# GutGenugInvisibles — INVINCIBLE: Wave Survival

A fan-made web game inspired by the Invincible comic/show by Robert Kirkman.

## ▶ Play Now
Open `index.html` directly in your browser, or host via **GitHub Pages** — no install, no app, just play!

## Characters
| Hero | Type | Special (E) |
|------|------|-------------|
| Invincible (Mark) | Melee | Energy Burst — AOE knockback |
| Omni-Man | Melee | Ground Slam — massive knockback |
| Atom Eve | Ranged | Matter Shield — absorbs 3 hits |
| Allen the Alien | Melee | Power Punch — high-damage cone |
| Battle Beast | Melee | Berserker Rage — 2× speed & damage |
| Cecil Stedman 🃏 | Ranged (pistol) | TELEPORT — random position! (troll) |
| ⭐ Homelander | Melee | Laser Vision (unlock: beat the game) |
| ⭐ Soldier Boy | Ranged | Shield Blast (unlock: beat the game) |

## Wave Progression
| Waves | Content |
|-------|---------|
| 1–9 | Reanimen only |
| 10–19 | **Flaxan Invasion!** Reanimen + Flaxans |
| **Wave 20** | 👊 BOSS: The Mauler Twins |
| 21–29 | Reanimen + Flaxans + occasional Mauler Twin |
| **Wave 30** | 👊 BOSS: Conquest |
| 31–39 | Reanimen + Flaxans + Viltrimites (1–3 random) |
| **Wave 40** | 👊 BOSS: Angstrom Levy + 1–2 Evil Invincibles |
| 41–49 | Everything + occasional Evil Invincibles |
| **Wave 50** | 💀 FINAL BOSS GAUNTLET — all bosses → Grand Regent Thragg |

Beating the game **unlocks Homelander & Soldier Boy** (saved in browser localStorage).

## Controls
| Key | Action |
|-----|--------|
| WASD / Arrows | Move |
| E | Special Ability |
| P / ESC | Pause |
| Enter | Skip wave countdown |
| Auto | Character auto-attacks nearest enemy |

## Hosting on GitHub Pages
1. Go to **Settings → Pages** in this repository
2. Set source to `main` branch, root `/`
3. Your game will be live at `https://<username>.github.io/<repo>/`
